Problem Statement – Musical Playlist Manager using Doubly Linked List

To implement the Musical Playlist Manager, the C++ programming language is used along with the Doubly Linked List data structure. The system is designed to manage songs dynamically and provide easy playlist navigation. Each song is stored in a node containing the song name, artist name, and pointers to the previous and next songs.

The application allows users to add new songs, delete existing songs, search for specific songs, display the complete playlist, and navigate between previous and next songs. Dynamic memory allocation is used to create and delete nodes as required, while pointers maintain the connections between songs.

A menu-driven interface is developed to make the application simple and user-friendly. The program is compiled and tested in Visual Studio Code to ensure that all playlist operations work correctly. Finally, the C++ source code, README documentation, and other necessary files are uploaded to GitHub for project documentation, version control, and future improvements.

This project demonstrates the practical use of doubly linked lists, pointers, dynamic memory allocation, and basic data structure operations in a real-world music playlist management system.
