# Problem Statement – Musical Playlist Manager

In today's digital world, music is an important part of everyday life. People listen to music for entertainment, relaxation, education, and motivation. Managing a collection of songs efficiently requires a system that allows users to organize their music, access their favorite songs, and navigate between tracks easily. However, managing playlists manually can become difficult when the number of songs increases. Users may face problems when adding new songs, deleting unwanted songs, searching for a particular song, displaying the complete playlist, and moving between previous and next songs.

The **Musical Playlist Manager** is a C++ application developed to solve these problems by providing a simple and efficient way to manage a music playlist. The project uses the **Doubly Linked List** data structure to store and organize song information dynamically. Each node represents a song and contains details such as the song name, artist name, and links to the previous and next songs. This structure allows users to move both forward and backward through the playlist.

The system provides various operations, including adding new songs, deleting existing songs, searching for a particular song, displaying all songs in the playlist, and navigating to the previous or next song. It also demonstrates how linked lists can manage data dynamically without requiring a fixed amount of memory in advance.

The main objective of this project is to develop a user-friendly, menu-driven music playlist management system while applying fundamental data structure concepts in a practical application. It helps improve the understanding of pointers, dynamic memory allocation, node creation, insertion, deletion, traversal, and searching operations in C++.

Therefore, the Musical Playlist Manager provides a practical example of how data structures can be used to solve real-world problems. It makes playlist management more organized and convenient while helping students understand the importance of data structures in software development.
