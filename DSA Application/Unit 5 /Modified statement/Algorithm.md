1.Start the program.

2.Input the number of substations and power lines.

3.Store substations as vertices and power lines as weighted edges.

4.Display the original graph.

5.Perform BFS from a selected substation and check connectivity.

6.If the graph is connected, calculate the MST cost using Kruskal’s algorithm; otherwise, display that an MST does not exist.

7.Allow the user to add a new substation or a new power line.

8.Display the updated graph.

9.Repeat BFS and Kruskal’s algorithm on the updated graph.

10.Compare the original and updated traversal and MST results.

11.Display the results and stop.
