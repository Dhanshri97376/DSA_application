Problem Statement

Develop a C++ program to represent a power network using a graph, where power substations are represented as vertices and power lines as weighted edges. The program should allow users to add new substations or power lines dynamically and display the updated graph. It should apply Breadth-First Search (BFS) to check the reachability of substations and Kruskal’s algorithm to calculate the Minimum Spanning Tree (MST) cost. The program should compare the results before and after updates and handle disconnected substations or unavailable paths by displaying appropriate messages.
