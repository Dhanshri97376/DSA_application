Develop a C++ program to represent power substations as vertices and power lines as weighted edges in a graph. Apply Breadth-First Search (BFS) or Depth-First Search (DFS) to check the reachability of all substations from a selected substation. If the graph is connected, apply Kruskal’s algorithm to calculate the Minimum Spanning Tree (MST), which gives the minimum total cost required to connect all substations.

The program should display the graph connections, reachable substations, selected minimum-cost power lines, and the total MST cost. If the graph is disconnected, it should display an appropriate message.
