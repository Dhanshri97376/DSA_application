Develop a C++ program to implement an AVL tree and detect imbalances that occur during the insertion of nodes. An AVL tree is a self-balancing binary search tree in which the height difference between the left and right subtrees of every node must not exceed one. The program should calculate the balance factor of each node after insertion and identify the four types of imbalances: Left-Left (LL), Right-Right (RR), Left-Right (LR), and Right-Left (RL). Based on the detected imbalance, the program should perform the appropriate single or double rotation to restore the balance of the tree. Finally, the program should display the balanced AVL tree and demonstrate how rotations maintain the tree's balanced structure and efficient searching, insertion, and deletion operations.
