AVL Tree Imbalance Detection and Automatic Balancing Using C++**

Develop a C++ program to implement an AVL tree that automatically detects and corrects imbalances during node insertion. The program should accept user input, insert nodes according to the Binary Search Tree (BST) property, update node heights, and calculate balance factors to determine whether the tree is balanced. It should identify LL (Left-Left), RR (Right-Right), LR (Left-Right), and RL (Right-Left) imbalance conditions and perform the appropriate single or double rotations to restore balance. Finally, the program should display the type of imbalance detected, the rotation performed, and the inorder traversal of the balanced AVL tree, demonstrating the efficient maintenance of a self-balancing tree.
