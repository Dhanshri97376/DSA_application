Algorithm: 
1. Start the program.
2. Create a binary tree with predefined nodes.
3. Enter the value of the node to be checked.
4. Search for the specified node in the binary tree.
5. If the node is not found, display “Node not found.”
6. If the node is found, check its left and right child pointers.
7. If both children exist, display “Both children.”
8. If only the left child exists, display “Left child only.”
9. If only the right child exists, display “Right child only.”
10. If neither child exists, display “No children (leaf node).”
11. Stop the program.
